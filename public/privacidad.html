Información sobre privacidad

El formulario de este portafolio recoge tu nombre, correo electrónico, servicio de interés, presupuesto aproximado y mensaje para responder a solicitudes sobre proyectos web. La información se utiliza exclusivamente para gestionar estas consultas.

Tratamiento y proveedor

Si el sitio está publicado en Netlify, los datos del formulario se procesan mediante Netlify Forms. Las solicitudes pueden consultarse desde el panel del sitio. No se usan para boletines, publicidad ni ventas de datos.

Consentimiento

Al enviar el formulario aceptas este uso de la información. No incluyas contraseñas, datos bancarios u otra información sensible en el mensaje.

Consultas y eliminación

Puedes solicitar acceso, corrección o eliminación de la información mediante el formulario del portafolio indicando el asunto de tu solicitud.

Nota de publicación

El titular debe completar y revisar este aviso, establecer un plazo de conservación y verificar las obligaciones de protección de datos que correspondan antes de usar el formulario comercialmente. Este texto es una base informativa y no certifica cumplimiento legal.
